# Веб‑приложение классификации и анализа вакансий работодателей

---

## 📌 О проекте
Веб‑приложение для автоматизации анализа вакансий и предварительного отбора кандидатов на основе методов машинного обучения.

Система предназначена для поддержки процессов подбора персонала и позволяет:

- управлять вакансиями и резюме соискателей;
- автоматически оценивать соответствие кандидатов требованиям вакансии;
- формировать аналитические отчёты;
- разграничивать доступ пользователей по ролям;
- визуализировать статистику работы системы.

Проект разработан в рамках выпускной квалификационной работы.

---

## ⚙️ Технологический стек

### Backend
- Python 3.11+
- Django
- Django REST Framework
- PostgreSQL
- PyTorch
- Sentence-Transformers

### Frontend
- Vue.js
- HTML/CSS

### Machine Learning
- Генерация текстовых векторных представлений (SentenceTransformer)
- Многослойный перцептрон (MLP) для бинарной классификации
- Оценка соответствия в диапазоне от 0 до 1

---

## 🤖 Принцип работы интеллектуального анализа

1. Текст вакансии и резюме приводится к унифицированному формату.
2. Формируются текстовые векторные представления.
3. Вектор вакансии и резюме объединяются.
4. MLP‑модель вычисляет степень соответствия.
5. Результат отображается в виде процента релевантности.

## 🚀 ИНСТРУКЦИЯ ПО СБОРКЕ И ЗАПУСКУ ПРОГРАММЫ
### 1. Требования к программному обеспечению
Для корректной работы системы необходимо наличие следующего программного обеспечения:
- Python версии 3.10 и выше
- Git
- PostgreSQL
- Операционная система Windows / Linux / macOS
### 2. Клонирование репозитория
Выполнить команду в терминале:
```
bash
git clone https://github.com/NikitinAnton/vacancy-analysis.git
cd vacancy-analysis/backend
```
### 3. Создание виртуального окружения
Создать и активировать виртуальное окружение:   
Windows:
```
bash
python -m venv .venv
.venv\Scripts\activate
```
Linux/macOS:
```
bash
python3 -m venv .venv
source .venv/bin/activate
```
### 4. Установка зависимостей
Установить необходимые библиотеки:
```
bash
pip install -r requirements.txt
```
### 5. Настройка базы данных
В файле config/settings.py при необходимости указать параметры подключения к PostgreSQL.
```
python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'vacancy_db',       # Имя базы данных (создайте её заранее)
        'USER': 'postgres',        # Имя пользователя PostgreSQL
        'PASSWORD': 'postgres',    # Пароль (по умолчанию 'postgres')
        'HOST': 'localhost',       # Хост (если БД на этом же компьютере)
        'PORT': '5432',            # Порт PostgreSQL
    }
}
```
#### Примечание:
Перед запуском создай базу данных vacancy_db в PostgreSQL:
```
sql
CREATE DATABASE vacancy_db;
```
Выполнить миграции:
```
python manage.py migrate
```
### 6. Инициализация начальных данных
Создать роли пользователей и базовые записи:
```
python
python manage.py init_data
```
### 7. Запуск сервера
Запустить сервер разработки:
```
python
python manage.py runserver
```
После запуска система будет доступна по адресу:
http://localhost:8000/
### 8. Запуск модуля машинного обучения
Файл обученной модели mlp_model.pkl должен находиться в каталоге:
backend/app/ml/
Модель загружается автоматически при первом обращении к функции анализа.
