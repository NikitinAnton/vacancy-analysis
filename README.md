# Веб‑приложение классификации и анализа вакансий работодателей

---

## 📌 О проекте
Веб‑приложение для автоматизации анализа вакансий и предварительного отбора кандидатов на основе методов машинного обучения.

Система предназначена для поддержки процессов подбора персонала и позволяет:

- управлять вакансиями и резюме соискателей;
- автоматически оценивать соответствие кандидатов требованиям вакансии;
- формировать аналитические отчёты;
- разграничивать доступ пользователей по ролям;
- визуализировать статистику работы системы.

Проект разработан в рамках выпускной квалификационной работы.

---

## ⚙️ Технологический стек

### Backend
- Python 3.11+
- Django
- Django REST Framework
- PostgreSQL
- PyTorch
- Sentence-Transformers

### Frontend
- Vue.js
- HTML/CSS

### Machine Learning
- Генерация текстовых векторных представлений (SentenceTransformer)
- Многослойный перцептрон (MLP) для бинарной классификации
- Оценка соответствия в диапазоне от 0 до 1

---

## 👥 Ролевая модель доступа

### 🔐 Администратор
- управление пользователями;
- просмотр системного дашборда;
- журнал действий;
- резервное копирование данных.

### 👩‍💼 HR-менеджер
- создание и редактирование вакансий;
- добавление резюме;
- запуск анализа соответствия.

### 📊 Руководитель
- просмотр аналитического дашборда;
- оценка результатов анализа;
- изменение статуса резюме.

---

## 🤖 Принцип работы интеллектуального анализа

1. Текст вакансии и резюме приводится к унифицированному формату.
2. Формируются текстовые векторные представления.
3. Вектор вакансии и резюме объединяются.
4. MLP‑модель вычисляет степень соответствия.
5. Результат отображается в виде процента релевантности.
